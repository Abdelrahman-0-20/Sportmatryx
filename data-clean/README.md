# Sportmetryx Football — clean data export

Curated, human-readable CSVs. Athlete **names instead of raw IDs**, joined
across tables, sorted by athlete then date. All data is synthetic demo data
(generated by `prisma/seed.ts`) — no real athletes.

| File | Rows | Contents |
|---|---|---|
| `00-users.csv` | 6 | Demo accounts (email, name, role) |
| `01-roster.csv` | 50 | Full roster: team, position, role, status, birth year, consent status |
| `02-baselines.csv` | 50 | Per-athlete own-baselines (type, window, status, notes) |
| `03-training-sessions.csv` | 350 | Sessions joined with football context (opponent, venue, surface, drill, air quality, travel) |
| `04-performance-scores.csv` | 682 | Composite scores: score, band, confidence, validity state + reason |
| `05-score-components.csv` | 4,774 | The 7 components behind each score (normalized, original, weight, contribution) |
| `06-score-drivers.csv` | 3,039 | Explainability drivers (positive/negative, description, strength) |
| `07-validity-checks.csv` | 3,422 | Fail-closed validity gates per score (check, status, reason) |
| `08-observations.csv` | 19,732 | Raw measurement stream (HR, RHR, RESP_RATE, TZ_SHIFT_H, …) with source + validity |
| `09-consent-records.csv` | 50 | Consent types, statuses, grant/revoke times |
| `10-interventions.csv` | 6 | Intervention queue (exception, priority, status, window) |
| `11-intervention-reviews.csv` | 4 | Reviewer decisions |

## Score / observation relationship
`04-performance-scores.csv` → one row per score per athlete per day.
Its parts: `05` (components), `06` (drivers), `07` (validity gates) — join on
**Athlete + Score Timestamp**. The raw signals feeding scores are in `08`.

Regenerate anytime: `node data-export/export.mjs` (raw tables) —
the clean set is derived from the same database.
